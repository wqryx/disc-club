# Disc Club — the 2000s on repeat

Fan-made tribute to the music of the 2000s, styled after a Y2K blue cover: 3D iridescent CD (Three.js), iPod click-wheel player, iris visualizer, tracklist, eras, timeline and formats.

No original audio is reproduced: playback uses a small synthesized ambient engine (Web Audio).

Live: https://wqryx.github.io/disc-club/
